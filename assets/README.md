# Immagini

`logo-sapienza.png` è il logo fornito per la presentazione originale. Mantienine le proporzioni.

Aggiungi qui le figure delle nuove presentazioni. SVG è adatto a grafici vettoriali; PNG ad alta risoluzione è adatto a immagini raster.

Il logo mantiene i diritti del rispettivo titolare e non viene concesso in licenza dal codice di questo template. Per un template destinato a un pubblico generico si può sostituire con il proprio logo, aggiornando il percorso in `slides.qmd`.
